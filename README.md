# Java Blockchain Core Suite
✨ 基于 Java 开发的企业级区块链底层核心工具集 | 全模块原创实现 | 无第三方依赖 | 开箱即用

一个专注于区块链底层技术的纯 Java 实现项目，覆盖**区块结构、加密算法、共识机制、P2P网络、智能合约、数字钱包、UTXO模型、默克尔树、跨链、零知识证明、联盟链**等全栈区块链技术。所有代码 100% 原创、无重复、无抄袭，适合学习研究、毕业设计、企业级区块链底层开发。

# 📁 项目文件清单（45个核心模块 · 文件名 + 详细功能）
本项目包含 45 个独立可运行 Java 类，每个文件负责一个区块链核心功能，无耦合、易理解、易扩展。

## 1. BlockChainCore.java
- 核心功能：区块链主链式结构管理，实现创世区块生成、区块添加、区块链完整性校验
- 技术价值：定义最基础的区块链数据结构，是整个系统的骨架
- 应用场景：公链/联盟链核心账本存储基础

## 2. EncryptUtil.java
- 核心功能：SHA-256 哈希加密工具类，区块链通用哈希算法
- 技术价值：保证数据不可篡改，所有区块、交易均依赖此加密
- 应用场景：区块哈希计算、数据摘要生成

## 3. ECCKeyGenerator.java
- 核心功能：椭圆曲线加密（ECC）secp256k1 密钥对生成（比特币/以太坊同款算法）
- 技术价值：非对称加密基础，用于身份签名、验签
- 应用场景：钱包密钥生成、节点身份认证

## 4. ProofOfWork.java
- 核心功能：工作量证明（PoW）挖矿算法，实现难度控制、Nonce 爆破
- 技术价值：公链核心共识，防止双花与恶意攻击
- 应用场景：比特币类公链挖矿机制

## 5. ChainStorage.java
- 核心功能：区块链账本本地文件持久化存储与加载
- 技术价值：保证节点重启后数据不丢失
- 应用场景：全节点数据备份、离线存储

## 6. TransactionSigner.java
- 核心功能：交易数据签名生成，使用 ECDSA 椭圆曲线签名
- 技术价值：确保交易发送者身份合法、交易不可伪造
- 应用场景：转账交易、合约调用签名

## 7. UTXOModel.java
- 核心功能：未花费交易输出模型，比特币核心交易机制
- 技术价值：实现去中心化账本的交易追踪
- 应用场景：加密货币交易、资产转移验证

## 8. LedgerValidator.java
- 核心功能：全账本完整性校验，检查区块哈希与前后链接关系
- 技术价值：快速判断区块链是否被恶意篡改
- 应用场景：节点同步校验、异常数据检测

## 9. DistributedSync.java
- 核心功能：分布式节点账本数据同步协议
- 技术价值：保证多节点数据一致性
- 应用场景：P2P 网络区块同步、跨节点数据对齐

## 10. PoSConsensus.java
- 核心功能：权益证明（PoS）共识机制，按持仓比例选择记账节点
- 技术价值：低功耗、高效率共识，替代 PoW
- 应用场景：以太坊、点点币等节能型公链

## 11. DPoSVoting.java
- 核心功能：委托权益证明（DPoS）投票选举模块
- 技术价值：通过社区投票选出超级节点，提升交易速度
- 应用场景：EOS、波场类联盟链/高性能公链

## 12. PBFTConsensus.java
- 核心功能：实用拜占庭容错（PBFT）共识算法
- 技术价值：支持恶意节点存在下的分布式一致性
- 应用场景：联盟链、政务链、金融链

## 13. NodeManager.java
- 核心功能：区块链网络节点注册、移除、列表管理
- 技术价值：维护全网有效节点列表
- 应用场景：P2P 网络节点发现

## 14. P2PBroadcaster.java
- 核心功能：P2P 网络消息广播，向全网节点发送区块/交易
- 技术价值：去中心化信息传播核心
- 应用场景：新区块广播、新交易通知

## 15. BlockSerializer.java
- 核心功能：区块对象序列化与反序列化
- 技术价值：实现区块在网络中的传输格式转换
- 应用场景：节点间数据通信、数据传输

## 16. SmartContractEngine.java
- 核心功能：智能合约基础执行引擎
- 技术价值：提供合约运行环境
- 应用场景：链上逻辑执行、DApp 开发

## 17. ContractPermission.java
- 核心功能：智能合约调用权限控制
- 技术价值：防止未授权地址调用敏感合约
- 应用场景：联盟链合约管理、权限系统

## 18. ContractStateStorage.java
- 核心功能：智能合约状态数据持久化存储
- 技术价值：保存合约运行结果与状态
- 应用场景：代币合约、NFT 合约状态管理

## 19. DIDGenerator.java
- 核心功能：去中心化身份（DID）生成工具
- 技术价值：Web3 去中心化身份体系
- 应用场景：链上身份、无账号登录

## 20. WalletAddressGenerator.java
- 核心功能：数字钱包地址生成（0x 开头标准格式）
- 技术价值：用户资产唯一标识
- 应用场景：加密货币钱包、转账地址

## 21. WalletKeyStorage.java
- 核心功能：钱包私钥加密存储，防止明文泄露
- 技术价值：保护用户资产安全
- 应用场景：本地钱包、硬件钱包安全模块

## 22. CrossChainProtocol.java
- 核心功能：跨链交易基础协议构建
- 技术价值：实现不同区块链间资产交互
- 应用场景：跨链转账、多链生态互通

## 23. MerkleTree.java
- 核心功能：默克尔树（Merkle Tree）根节点构建
- 技术价值：高效验证区块内交易完整性
- 应用场景：区块交易验证、轻节点证明

## 24. MerkleProof.java
- 核心功能：默克尔证明验证，快速校验交易是否存在
- 技术价值：轻节点无需下载全量区块即可验证交易
- 应用场景：SPV 轻钱包、区块链浏览器

## 25. DoubleSpendCheck.java
- 核心功能：双花交易检测，防止同一笔钱被重复使用
- 技术价值：区块链核心安全保障
- 应用场景：交易校验、防欺诈系统

## 26. TimestampCalibrator.java
- 核心功能：区块时间戳校准，防止节点恶意篡改时间
- 技术价值：保证区块时序合法
- 应用场景：区块生成、交易时序验证

## 27. DistributedRandom.java
- 核心功能：分布式公平随机数生成
- 技术价值：链上不可篡改、可验证随机数
- 应用场景：抽奖、游戏、公平选举

## 28. ChainDataQuery.java
- 核心功能：链上数据快速查询接口
- 技术价值：支持按区块高度检索数据
- 应用场景：区块链浏览器、数据统计

## 29. MaliciousNodeDetector.java
- 核心功能：恶意节点检测与识别
- 技术价值：提升网络安全性
- 应用场景：节点准入、黑名单机制

## 30. GasCalculator.java
- 核心功能：智能合约 Gas 费用计算
- 技术价值：控制合约执行成本
- 应用场景：以太坊类合约手续费模型

## 31. MemPoolManager.java
- 核心功能：交易池（MemPool）管理，缓存待打包交易
- 技术价值：矿工打包交易的核心模块
- 应用场景：挖矿节点、交易排队系统

## 32. LightNodeSync.java
- 核心功能：轻节点区块头同步
- 技术价值：轻量级节点无需下载全量数据
- 应用场景：手机钱包、轻量级客户端

## 33. FullNodeBackup.java
- 核心功能：全节点数据完整备份工具
- 技术价值：防止数据丢失，支持灾难恢复
- 应用场景：节点运维、数据安全

## 34. ChainLogger.java
- 核心功能：区块链系统日志记录模块
- 技术价值：便于调试、监控、审计
- 应用场景：节点运行监控、异常排查

## 35. TokenTransfer.java
- 核心功能：加密货币转账交易构建
- 技术价值：基础资产转移功能
- 应用场景：数字代币转账、支付系统

## 36. MultiSigVerify.java
- 核心功能：多重签名交易验证
- 技术价值：多用户共同授权才能完成交易
- 应用场景：共管钱包、企业账户、多签钱包

## 37. ConsortiumChainAuth.java
- 核心功能：联盟链节点准入权限管理
- 技术价值：只有授权节点才能加入网络
- 应用场景：金融联盟链、企业链、政务链

## 38. ZKProofTool.java
- 核心功能：零知识证明基础工具
- 技术价值：不泄露隐私即可证明合法性
- 应用场景：隐私交易、身份匿名验证

## 39. DataCompressor.java
- 核心功能：区块链数据压缩存储
- 技术价值：减少存储空间，提升传输效率
- 应用场景：轻节点、低成本节点

## 40. DataConsistencyCheck.java
- 核心功能：跨节点数据一致性校验
- 技术价值：确保全网账本统一
- 应用场景：分布式系统、多副本数据校验

## 41. ContractEventListener.java
- 核心功能：智能合约事件监听与触发
- 技术价值：实现合约与外部系统交互
- 应用场景：DApp 实时通知、链下监听

## 42. DifficultyAdjuster.java
- 核心功能：PoW 挖矿难度动态调整
- 技术价值：维持区块生成时间稳定
- 应用场景：公链挖矿难度自适应

## 43. AssetIssuer.java
- 核心功能：链上原生资产发行工具
- 技术价值：快速创建自定义代币/数字资产
- 应用场景：代币发行、积分系统、数字资产

## 44. DistributedLock.java
- 核心功能：分布式锁机制，保证并发安全
- 技术价值：防止多节点同时修改同一数据
- 应用场景：共识机制、交易处理

## 45. HeartbeatDetector.java
- 核心功能：区块链节点心跳检测
- 技术价值：判断节点是否在线
- 应用场景：P2P 网络健康监控、节点掉线感知
